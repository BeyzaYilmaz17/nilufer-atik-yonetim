# ♻️ Nilüfer Atık Yönetim Sistemi

Nilüfer Atık Yönetim, sürdürülebilir bir çevre ve daha temiz bir gelecek için geliştirilmiş, Flutter tabanlı bir mobil uygulamadır. Bu proje, atık toplama süreçlerini dijitalleştirerek geri dönüşümü teşvik etmeyi ve atık yönetimini optimize etmeyi amaçlar.

## 📱 Proje Hakkında

Bu uygulama, kullanıcıların atıklarını türlerine göre ayrıştırmasına, en yakın toplama noktalarını bulmasına ve atık yönetimi süreçlerine aktif olarak katılmasına olanak tanır.

**Temel Özellikler:**
* **Kullanıcı Dostu Arayüz:** Kolay anlaşılır ve erişilebilir tasarım.
* **Atık Ayrıştırma:** Kağıt, plastik, cam ve metal atıklar için rehberlik.
* **Harita Entegrasyonu:** En yakın atık toplama kutularının ve merkezlerinin harita üzerinde gösterimi.
* **Bildirim Sistemi:** Atık toplama günleri ve önemli duyurular için bildirimler.
* **[Varsa Ek Özellik]:** [Örneğin: Puan toplama sistemi, QR kod ile atık bırakma vb.]

## 🚀 Kurulum ve Çalıştırma

Bu projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları izleyin:

1.  Projeyi klonlayın:
    ```bash
    git clone [https://github.com/BeyzaYilmaz17/nilufer-atik-yonetim.git](https://github.com/BeyzaYilmaz17/nilufer-atik-yonetim.git)
    ```

2.  Proje dizinine gidin:
    ```bash
    cd nilufer-atik-yonetim
    ```

3.  Gerekli paketleri yükleyin:
    ```bash
    flutter pub get
    ```

4.  Uygulamayı çalıştırın:
    ```bash
    flutter run
    ```
